# Запуск программы на своём компьютере

Программа откроется в браузере по адресу **http://localhost:3000** и будет доступна только на этом компьютере.
Работает на Windows 10/11, macOS и Linux. Понадобится около 4 ГБ свободного места и интернет для первой установки.

## 1. Установить программы (один раз)

1. **Docker Desktop** — https://www.docker.com/products/docker-desktop/ → скачать для вашей системы → установить → запустить.
   На Windows установщик может попросить включить WSL 2 и перезагрузить компьютер — согласитесь.
   Дождитесь, пока в окне Docker Desktop появится «Engine running» (зелёный значок).
2. **Git** — https://git-scm.com/downloads (на Windows все параметры установки можно оставить по умолчанию).

## 2. Скачать программу (один раз)

Откройте терминал: на Windows — «PowerShell» (Пуск → набрать PowerShell), на macOS — «Терминал».

```bash
git clone https://github.com/kozhoevaeliza4-oss/-.git construction-registry
cd construction-registry
git checkout claude/qa-audit
```

Если GitHub спросит логин — войдите своей учётной записью GitHub (репозиторий закрытый).

## 3. Запустить

```bash
docker compose -f docker-compose.local.yml up -d --build
```

Первый запуск занимает 5–15 минут (скачиваются компоненты и собирается программа). Следующие запуски — секунды.

Создать администратора (один раз, после первого запуска):

```bash
docker compose -f docker-compose.local.yml exec app npx prisma db seed
```

По желанию — демо-проект с вымышленными данными для знакомства:

```bash
docker compose -f docker-compose.local.yml exec -e DEMO_PASSWORD=demo-password-1 app npx tsx prisma/demo.ts
```

## 4. Открыть

Браузер → **http://localhost:3000**
Логин: `admin@example.local` · пароль: `change-me-please`
(Сменить данные администратора: поправьте `SEED_ADMIN_EMAIL` и `SEED_ADMIN_PASSWORD` в `docker-compose.local.yml` до создания администратора.)

## Остановить и запустить снова

```bash
docker compose -f docker-compose.local.yml stop      # остановить (данные сохраняются)
docker compose -f docker-compose.local.yml start     # запустить снова
```

После обновления кода (`git pull`) — снова `docker compose -f docker-compose.local.yml up -d --build`.

## Если что-то не так

| Проблема | Что сделать |
|---|---|
| `docker: command not found` / «cannot connect to the Docker daemon» | запустите Docker Desktop и дождитесь «Engine running» |
| «port is already allocated» (порт 3000 занят) | в `docker-compose.local.yml` замените `127.0.0.1:3000:3000` на `127.0.0.1:3001:3000` и откройте http://localhost:3001 |
| Страница не открывается сразу после запуска | подождите 20–30 секунд; журнал: `docker compose -f docker-compose.local.yml logs app` |

## Важно

- Это режим для своего компьютера: без HTTPS и с простым паролем базы данных. Для работы сотрудников через сеть программу нужно
  разместить на сервере (см. `QA_FINAL_REPORT.md`, раздел 7).
- Данные хранятся внутри Docker (тома `pgdata-local`, `storage-local`). Команда `docker compose ... down -v` **удаляет все данные** — не используйте её без копии.
