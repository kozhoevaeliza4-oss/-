# Задачи руководителя

Простое мобильное приложение на двоих: **ассистент** добавляет задачи,
**руководитель** получает уведомление, открывает приложение и сразу видит,
что нужно сделать сегодня.

Приложение — PWA: открывается в браузере телефона и устанавливается на экран
«Домой», дальше работает как обычное приложение (своя иконка, полноэкранный
режим, push-уведомления). Магазины приложений не нужны.

## Что умеет

**Ассистент**
- добавляет задачу: название, короткое описание, дата (Сегодня / Завтра / другая),
  время (или «Без времени»), приоритет (Не срочно / Обычный / Важно);
- изменяет и удаляет задачи (нажать на карточку);
- видит задачи по дням, просроченные и выполненные руководителем;
- получает уведомление «Выполнено», когда руководитель закрыл задачу.

**Руководитель**
- главный экран: «Сегодня» + дата, задачи на сегодня по времени, отдельно — «Без времени»,
  внизу — счётчик «Выполнено / Осталось»;
- кнопка «Выполнить» на каждой задаче (повторное нажатие возвращает задачу, если нажали по ошибке);
- невыполненные задачи прошлых дней показываются сверху, в блоке «Не выполнено ранее».

**Уведомления руководителю**
- «Новая задача — Позвонить подрядчику — сегодня в 15:00» — сразу после добавления;
- «Через 30 минут — Позвонить подрядчику — сегодня в 15:00» — перед задачей
  (интервал настраивается `REMINDER_MINUTES`);
- «Задача изменена — …» — если ассистент перенёс время/дату или поменял название.

**Просрочено** — если время задачи прошло, а она не выполнена (для задач без
времени — когда закончился день), задача автоматически помечается «Просрочено».

**Синхронизация** — оба телефона видят изменения мгновенно (Server-Sent Events),
плюс обновление при каждом открытии приложения.

## Запуск

```bash
cd tasks-app
npm install
cp .env.example .env    # задайте ASSISTANT_PIN и BOSS_PIN
npm start               # http://localhost:3000
```

Тесты: `npm test`.

Вход: на первом экране выбрать «Руководитель» или «Ассистент» и ввести свой PIN.
Телефон запоминает вход. Чтобы разлогинить все устройства пользователя —
смените его PIN в `.env` и перезапустите сервер.

## Размещение на Render (самый простой путь)

В корне репозитория лежит `render.yaml` — готовые настройки.

1. Зарегистрироваться на [render.com](https://render.com) через GitHub.
2. **New → Blueprint** → выбрать этот репозиторий (и ветку с приложением).
3. Render спросит `ASSISTANT_PIN` и `BOSS_PIN` — придумать два PIN-кода.
4. Нажать **Apply** и подождать 2–3 минуты. Render выдаст адрес вида
   `https://boss-tasks.onrender.com` — с HTTPS, это и есть адрес приложения.

Стоимость: тариф Starter ~7 $/мес + диск 1 ГБ ~0,25 $/мес. Бесплатный тариф
не подходит: он «засыпает» без посещений (напоминания не придут) и не хранит
данные между перезапусками.

## Размещение на своём сервере

Push-уведомления и установка на экран «Домой» работают **только по HTTPS**.
Подойдёт любой VPS с Node.js 18+ за HTTPS-прокси (nginx, Caddy) или PaaS
(Render, Railway, Fly.io и т.п.) с постоянным диском для `data/`.

Пример для Caddy:

```
tasks.example.kg {
  reverse_proxy localhost:3000
}
```

Для nginx отключите буферизацию для `/api/events` (`proxy_buffering off;`),
иначе живая синхронизация будет с задержкой.

Данные хранятся в одном файле `data/db.json` (задачи, подписки на уведомления,
ключи). Для резервной копии достаточно копировать его.
**Не удаляйте** его при переезде: в нём VAPID-ключи — без них телефоны
перестанут получать уведомления, пока их не включат заново.

## Установка на телефон

**iPhone (iOS 16.4+)**: открыть адрес в Safari → «Поделиться» → «На экран „Домой“» →
открыть приложение с экрана «Домой» → войти → «Включить уведомления».
На iPhone уведомления работают только в приложении, установленном на экран «Домой».

**Android**: открыть адрес в Chrome → «Установить приложение» (или меню ⋮ →
«Добавить на главный экран») → войти → «Включить уведомления».

## Устройство

```
src/
  server.js     запуск: ключи, PIN-коды, таймер напоминаний
  app.js        HTTP API (Express) + живая синхронизация
  tasks.js      валидация задачи, статус «Просрочено», тексты «сегодня в 15:00»
  reminders.js  напоминания за N минут
  push.js       отправка Web Push
  auth.js       вход по PIN, подписанные токены, защита от перебора
  store.js      хранение в JSON-файле (атомарная запись)
  time.js       даты в часовом поясе приложения (APP_TIMEZONE)
public/
  index.html, app.js, styles.css   интерфейс
  sw.js                            service worker: уведомления и офлайн-оболочка
  manifest.webmanifest, icons/     установка на экран «Домой» (иконки: npm run icons)
```

API (все запросы, кроме входа, — с `Authorization: Bearer <token>`):

| Метод | Путь | Кто | Что делает |
|---|---|---|---|
| POST | `/api/login` | все | `{role, pin}` → `{token}` |
| GET | `/api/tasks` | оба | список задач со статусом |
| POST | `/api/tasks` | ассистент | создать задачу |
| PATCH | `/api/tasks/:id` | ассистент | изменить |
| DELETE | `/api/tasks/:id` | ассистент | удалить |
| POST | `/api/tasks/:id/done` | оба | `{done: true/false}` |
| POST | `/api/push/subscribe` | оба | подписать устройство на уведомления |
| GET | `/api/events` | оба | поток изменений (SSE) |

Сознательно **не** сделано (по ТЗ — не перегружать): проекты, чаты, аналитика,
повторяющиеся задачи, комментарии.
